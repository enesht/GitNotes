# Markdown Kullanım Kılavuzu

Markdown, web için yazı yazmanın en kolay yoludur. İşte temel söz dizimi:

## Başlıklar

```markdown
# H1 Başlık
## H2 Başlık
### H3 Başlık
```

## Metin Biçimlendirme

- **Kalın metin** için `**kalın**`
- *İtalik metin* için `*italik*`
- ~~Üstü çizili~~ için `~~üstü çizili~~`

## Listeler

### Sırasız Liste
- Öğe 1
- Öğe 2
  - Alt öğe
  - Alt öğe 2

### Sıralı Liste
1. Birinci madde
2. İkinci madde
3. Üçüncü madde

## Kod Blokları

Satır içi kod için: `const x = 10;`

Kod bloğu için:

```javascript
function merhaba() {
  console.log("Merhaba Dünya!");
}
```
